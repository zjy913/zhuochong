# 🐾 桌面宠物 Desktop Pet

一个用 **Electron** 制作的 Windows 桌面宠物，可以实现：
- 透明、无边框、置顶的宠物窗口，浮在桌面上
- 右键/按住**拖动**到任意位置
- **双击**宠物会通过气泡说话
- 细腻的待机呼吸浮动动画

---

## 🚀 怎么运行

### 方式一：打包成 exe 直接双击（推荐，不需要终端）

最省事的方式——桌宠已经被打包成了一个独立的可执行文件：

1. 去 `dist/` 目录，找到 **`DesktopPet <版本>.exe`**（如 `DesktopPet 1.0.0.exe`）
2. **双击它**即可运行，完全不需要终端、不需要装任何东西。

> 这是一个"单文件便携版"（约 68MB）。第一次运行会自动把桌宠注册为"开机自启"，之后**每次开机桌宠会自动出现**，全程无需任何操作。
> 若想取消自启，用命令行以 `--no-autostart` 启动一次即可。

### 🚪 怎么退出桌宠

桌宠是无边框、透明、置顶的小窗口，所以**没有标题栏的关闭按钮**，请用下面任意一种方式退出：

| 方式 | 怎么做 |
|------|--------|
| **托盘图标（推荐）** | 鼠标移到屏幕右下角系统托盘，找到桌宠的黄色小图标：**右键 →「退出桌宠」**；左键单击可"显示/隐藏"宠物 |
| **右键宠物本体** | 在宠物身上点**鼠标右键**，会弹出一个菜单，点「退出桌宠」 |

> 托盘图标即使桌宠窗口被「隐藏」也一直存在，随时可以退出。

### 方式二：源码开发模式（需要终端）

当你需要改代码时，才用这种方式：

```bash
npm install        # 安装依赖（只需一次）
npm start          # 启动
```

如果一切正常，屏幕右下角会出现一只黄色的小团子，你可以拖动它、双击它聊天。

> 首次运行需要等 Electron 下载，请保持网络畅通。

## 📁 项目结构

```
desktop-pet/
├── main.js          # 主进程：创建透明置顶窗口 + IPC + 触发开机自启
├── preload.js       # 安全桥：暴露给页面 window.petAPI
├── autostart.js     # 开机自启：用任务计划程序注册登录时启动
├── index.html       # 宠物页面：贴图、气泡、拖拽、动画全部在这里
├── assets/
│   └── pet.svg      # 宠物形象（可替换为你自己的图）
└── dist/            # 打包产物
    └── DesktopPet 1.0.0.exe   ← 双击即用，无需终端
```

### 重新打包 exe

改完代码后，重新生成 exe：

```bash
npm run dist
```

产物在 `dist/DesktopPet <版本>.exe`。

## 🎮 怎么改我看得懂

### 1. 换头像
把图片放进 `assets/` 目录，命名成以下任意一个即可，代码会**自动识别**，不用改任何代码：

> 优先级：`pet.jpg` → `pet.png` → `pet.gif` → 内置 `pet.svg`（兜底）

```text
assets/
├── pet.jpg   ← 把你的 JPG 命名成它
├── pet.png   ← （可选）透明背景的 PNG
├── pet.gif   ← （可选）动图
└── pet.svg   ← 内置兜底
```

> ⚠️ **JPG 注意**：JPG 不支持透明背景。如果你的 JPG 带纯色背景（如白色），宠物会显示成一个"方框"贴在桌面上。要想像现在这样"浮"在桌面上，请用**已抠图/背景透明的 PNG**；如果带背景色也能接受，直接用 JPG 即可（资源开销也小）。

> 💡 喜欢动图？把 `pet.gif` 放进去，桌宠立刻"会动"。更高级的做法是多帧精灵图 + JS 切换，做"走路""眨眼"等状态。

### 2. 改说的话
双击后会随机弹一句话，去 `index.html` 里找到：

```js
const PHRASES = ["你好呀！(≧▽≦)", "...", ...];
```

在这里增删句子即可。

### 3. 调窗口大小 / 位置
- 窗口大小：`main.js` 里的 `PET_W` / `PET_H`
- 默认落地位置：`index.html` 的 `placePetAtStart()` 函数里的偏移量

## 🔧 核心技术点（给想深入的人）

| 需求 | 实现方式 |
|------|---------|
| 无边框窗口 | `frame: false` |
| 透明背景 | `transparent: true` + 页面背景 `transparent` |
| 永远置顶 | `alwaysOnTop: true` |
| 拖拽窗口 | 捕获 `pointerdown/move/up`，`requestAnimationFrame` 每帧合并一次坐标再发送 |
| 页面移动窗口 | 通过 `preload.js` + `ipcRenderer` 转发到主进程 `win.setBounds()`，主进程用微定时器合并高频 IPC，避免积压 |
| 让宠物贴屏幕底部 | 主进程 `screen.getPrimaryDisplay().workArea` 拿到可用区域 |

这三种"角色"每做一个桌宠都会遇到：
- **main.js —— 主进程**：管窗口本身（大小、位置、置顶、透明）
- **preload.js —— 桥**：因为安全策略，页面不能直接碰窗口，需要桥
- **index.html —— 渲染进程**：画宠物、接鼠标、播动画、弹气泡，业务都在这里

## 🚧 常见问题

- **窗口闪黑？** 确保 `transparent: true` 且页面 `body { background: transparent }`；个别显卡驱动可尝试在 `main.js` 的 `BrowserWindow` 配置里加 `backgroundColor: "#00000000"`。
- **拖不动/太灵敏？** 拖动逻辑在 `index.html` 的 `pointermove` 中，可加一点平滑（记录上次坐标做插值）。
- **想自动开机自启？** 后面可以加 `app.setLoginItemSettings(...)` 实现。
